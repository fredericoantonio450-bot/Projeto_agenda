Checkpoint

## Sobre o Projeto 
Unindo lógica de programação, design e criatividade, desenvolvido como parte de um trabalho avaliativo da turma de Técnico em informática.
Por tanto, Mais do que um exercício técnico, criamos algo que representa uma paixão em comum: **o universos do games**.

----

## Passo a passo para abrir/executar
1. Descompacte o arquivo `.zip` e entre na pasta **CheckPoint**, onde está o arquivo `index.php`.
2. Abra um treminal nessa pasta e execute: ```bash php -S localhost:8000```
3. Acesse no navegador: [http://localhost:8000](http://localhost:8000).
4. Se prefirir usar **XAMPP/WAMP**, copie a pasta `CheckPoint` para `htdocs` e acesse em: [http://localhost/CheckPoint](http:/localhost/CheckPoint),

----

## 💻 Requisitos
- Navegador atualizado (**Chrome, Firefox, Edge... **)
- *PHP 7.4+**  ou pacote como **XAMPP/WAMP** (incluem Apache e PHP
